# Antigravity Workspace Directory

โฟลเดอร์นี้จัดทำขึ้นตามคำสั่งเพื่อใช้เป็นที่จัดเก็บไฟล์, บันทึกการทำงาน (handoff/notes), และ cache ที่สร้างขึ้นโดย Antigravity

## โครงสร้างที่แนะนำ
- `.Antigravity/cache/` - สำหรับ cache หรือ temporary files ที่สร้างโดย Antigravity
- `.Antigravity/notes/` - สำหรับเอกสารสรุป, บันทึกความคืบหน้า หรือ scratch files ของ Antigravity
